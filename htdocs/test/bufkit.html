Listed below are quick links to several Bufkit resources I've collected to help those interested in the software, especially if you live in Iowa.

    Standard Bufkit Installation Download

    - This zip file will put all of the essentials on your machine to run Bufkit, also available here. After opening the zip file, simply run "setup.exe". (last update 11 October 2006)

    Iowa Bufkit Installation Download

    - This zip file was created by me to help those who wish to run Bufkit with the idea to forecast specifically for Iowa. This includes the .cty & .cfg listed under the Helpful Files. After opening the zip file, simply run "setup.exe". In addition, the BufGet and Convective Storm Matrix downloads are included.

    BufGet Installation Download

    - This exe file will enable the Bufget script provided in the Bufkit Download, also available here.

    Convective Storm Matrix Download

    - This file will make use of the CONRAD button on the main panel. When convective storms are forecast by the model, a letter and number will appear where a green dash is present otherwise. Then just select one of the four buttons to load the matrix.

Helpful Files:

    Bufkit4.exe - The latest build of Bufkit. When opening Bufkit from BufGet, you may get an error saying, "Bufkit4.exe" cannot be located. Save this in the Bufkit directory to fix this error.

    Bufget4.tcl - Tcl Script to run Bufkit using BufGet. When opening Bufkit from BufGet, you may get an error saying, "Bufkit4.exe" cannot be located. Save this in the Bufkit directory to fix this error.

    Bufkit.cfg - Configuration file that places several profiles in and near Iowa in the Bufkit station selection bar (Example). Overwrite the current Bufkit.cfg file by saving in the Bufkit directory.

    Bufkit.cty - This file will reconfigure the map so that Iowa cities will be displayed for easy viewing (Example). Overwrite the current bufkit.cty file by saving in the Bufkit directory.

Data Sources:

    Iowa Profiles - Links to all profiles centered around Iowa. You can copy these links straight into Bufget, or copy this file into the Bufkit directory.

    Individual Iowa Profiles - Supplied by the Des Moines NWS. Copy the links into BufGet, or save the files into the /Data directory.

    National Profile Selection - Click on the Model/Run you want, and a map of the U.S. will pop up with sites all over the nation to choose from. Copy the link address into BufGet, or save the link into the /Data directory.

    Bufkit Data Archive - The only archive I know about. Files supplied by the Des Moines NWS are available beginning 25 January 2006, located in a sub-directory called 'Bufkit'. Save these files into the /Data/Archive directory for storage. To view, place in /Data directory. Thank Daryl the next time you see him.

Documentation:

    Bufkit 4 Overview Briefing - Powerpoint made by Ed Mahoney of the WDTB.

    Strengths and Weakness of P-type Algorithms - Jobsheet supplied by NWS that uses Bufkit, included in the zip file.

    Strengths and Weakness of P-type Algorithms Part 2 - Excellent explanation of the Bourgouin P-type algorithm and partial thickness thresholds!

    Snowfall Forecasting - Jobsheet supplied by NWS that uses Bufkit, included in the zip file.

    Using Bufkit to Visualize Precipitation Amount and Type - Powerpoint presentation from the WDTB Winter Weather Workshop on July 23, 2003.

    Using Bufkit to Diagnose Winter Weather - Powerpoint presentation given by Rich Kinney (NWS Des Moines) on using bufkit, at the Central IA NWA meeting 12-5-07

    Using BUFKIT to Display and Analyze Meteorological Data - Powerpoint presentation prepared by Sean Nolan and Scott Jackson for the 2005 National Air Quality Conference.

    A Simple Physically Based Snowfall Algorithm - Dan Cobb (MIC at NWS GRR) and Jeff Waldstreicher developed a top-down algorithm for determining precip-type utilizing Bufkit data files. Profiles are sent to a perl script and posted online thanks to Rob Dale. Local sites include Des Moines, Mason City, Ottumwa, Davenport, Sioux Falls, and Omaha.
